## First email

Subject: Evidence for AI-assisted code changes

Hello,

I noticed your engineering team has publicly discussed using Claude Code for software delivery.

As AI coding agents take on larger changes, reviewers need evidence beyond an agent's completion summary: whether the session stayed within its agreed file scope, which tools ran, and whether acceptance checks passed.

Work Receipts is an Enock Labs plugin for Claude Code. It applies a human-written session contract, records tool activity, checks changed files against Git evidence, and produces a receipt that reviewers can independently verify.

We are inviting a small number of engineering teams to evaluate the workflow on one non-production repository. The evaluation includes setup, permitted and blocked scenarios, and a findings report. No broad platform commitment is required.

Would you be interested in receiving the technical brief and sample receipt?

Regards,
Enock Labs
